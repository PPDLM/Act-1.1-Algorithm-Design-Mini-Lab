# Problem B: Minimum Meeting Rooms

## Description
This program calculates the minimum number of rooms required to schedule a list of meetings using a Greedy sweep-line algorithm.

## How to Run
Navigate to this folder, compile, and run with the provided tests:
```bash
g++ -std=c++17 -O2 -Wall -Wextra -pedantic main.cpp -o main
./main < tests/input1.txt
```
