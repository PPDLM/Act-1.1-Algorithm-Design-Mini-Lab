# Algorithm Design Mini-Lab

## Overview
This repository contains solutions for three algorithm design problems using Divide & Conquer, Greedy, and Dynamic Programming techniques.

## Compilation
Navigate to a problem directory and compile the solution using C++17:
```bash
g++ -std=c++17 -O2 -Wall -Wextra -pedantic main.cpp -o main
```

## Execution
Run the compiled executable and pass the input via standard input (stdin):
```bash
./main < tests/input1.txt
```

## Structure & Assumptions
* Each problem is contained in its respective directory (`problemA_inversions`, `problemB_rooms`, `problemC_knapsack`).
* Standard input/output is used for all problems.
* Time and space complexities are documented in `report.md`.
