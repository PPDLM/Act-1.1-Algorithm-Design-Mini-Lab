# Problem A: Inversion Counter

## Description
This program calculates the number of inversions in an array using a Divide and Conquer approach (modified Merge Sort).

## How to Run
Navigate to this folder, compile, and run with the provided tests:
```bash
g++ -std=c++17 -O2 -Wall -Wextra -pedantic main.cpp -o main
./main < tests/input1.txt
```
